核心功能

专为看图体验打造，简洁高效，开箱即用

多图源聚合

内置 6 个图源接口（标准美图 / 二次元 ACG 等），支持用户自定义 API 图源，实现个性化内容聚合。

随机 + 顺序浏览

一键随机切换，支持上一张 / 下一张顺序浏览，循环播放，双击图片快速翻页。

本地保存

图片一键保存至手机相册，自动创建“随机看图”文件夹，方便管理。

智能缓存

5 分钟缓存机制，有效减少重复请求，提升加载速度，节省流量。

AndLua+ 原生

纯 Lua 脚本编写，无需复杂环境即可快速打包 APK，适合个人开发者快速迭代。

清爽 UI

蓝色渐变主题 + 圆角卡片式布局，设置菜单集成赞助、上传、官网、社群入口。
